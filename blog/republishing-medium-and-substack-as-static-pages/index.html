Turning Medium and Substack RSS feeds into static pages

26 October 2026 · 2 min read

I wanted my old Medium and Substack posts on my own domain. Both platforms put the full post body in their RSS feeds, inside <content:encoded>:

https://<you>.medium.com/feed
https://<you>.substack.com/feed

What is in the Medium feed

  • Only the latest 10 posts. If you have more, you need the export from Settings.
  • A 1×1 tracking image from medium.com/_/stat at the end of every post.
  • Images hotlinked from cdn-images-1.medium.com, with no file extension in the URL.
  • Section headings are <h3>, and the title is repeated as a bold first paragraph. Shift headings up a level once the title becomes the page's <h1>.
  • Code blocks come through as plain <pre>, which is the nice part.

What is in the Substack feed

  • The subscribe widget: a <form>, <button>, <input> and inline <svg>.
  • A "Thanks for reading …! Subscribe for free" paragraph.
  • Images through substackcdn.com with a long transformation URL.

The bug

My first sanitizer used Python's HTMLParser with a skip counter: add one on a <form>, <button>, <input> or <svg> start tag, subtract one on the matching end tag, and drop all text while the counter is above zero.

<input> is a void element. It never has an end tag, so the counter never came back to zero and everything after the subscribe widget silently vanished. A 24 KB post came out as 76 words. After ignoring void tags it was 838.

if t in ("input", "source"):   # void elements: no end tag will ever come
    return
if t in DROP:
    self.skip += 1
    ...

The tell was the word count. I now print one for every post and compare it with the original.

Smaller things

  • Name downloaded images by sniffing the first bytes (\x89PNG, \xff\xd8\xff), not by the URL.
  • Strip utm_* parameters from links.
  • Put an "originally published on" note on each page and set the page's canonical to itself. Then point the Medium original at your copy: story settings, Advanced settings, Customize canonical link.
