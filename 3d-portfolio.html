Interactive 3D projects

Three projects that show how I build 3D experiences: a compliance-style training simulation in Unity, a collection of web games in Three.js, and a mobile runner in Defold. Each one is playable from the link below.

Unity · training simulation

Safety Procedure Trainer

A 3D learning and simulation prototype for regulated manufacturing. Operators sign in, then work through a procedure: lock-out/tag-out on a packaging press, a hygiene gowning-room entry, or dressing a colleague for a cleanroom (wrong items are refused, right ones fly onto the mannequin). Out-of-order clicks are logged as deviations, a quiz follows, and every event goes into a tamper-evident, hash-chained audit log. SOP content is JSON, so a new revision needs no code change.

Defold · mobile rhythm runner

Beat Runner

A three-lane rhythm runner built in Defold for iOS, Android, HTML5 and desktop from one codebase. Features a curved-world vertex shader (the track rolls away under a globe horizon), roof-running ramps, composed obstacle props and a full meta layer: daily login, missions, seasons, store and events.
